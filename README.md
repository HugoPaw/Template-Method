# Template Method Beispiel in C#

Dieses Projekt zeigt das Template Method Design Pattern in C#

Ein Ablauf wird in der Basisklasse festgelegt  
Nur einzelne Schritte werden in den Unterklassen angepasst

Beispiel mit E-Mail Benachrichtigungen  
Der Ablauf zum E-Mail senden ist immer gleich  
Nur der Inhalt der Nachricht ändert sich

Verwendet wird eine abstrakte Klasse mit einer festen Methode  
Diese ruft andere Methoden auf die überschrieben werden können

Das Projekt ist für Lernzwecke gedacht
